# Blackjack
This code is a working Blackjack game for one user 

In order to run this code(through VS Code), you must first download the C/C++ DevTools and Extension pack from Microsoft in order to run this C++ code
Then you must make sure you have the C/C++ debugger active on VS Code
After checking these prerequisites, you will be able to compile and debug your code
After your code is compiled and debugged, you will need to run it manually, using the terminal and type "/.blackjack"
